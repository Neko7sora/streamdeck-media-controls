First-time setup

Requires Windows 10 (1809)+ x64, Stream Deck 7.1+, the Media Controls plugin and Node.js 24+. This extension cannot work on its own.

  1. Open Media Controls settings in Stream Deck.
  2. Enter this extension’s ID from chrome://extensions, then click “Register Chrome integration”.
  3. Enable sending above, then save.
  4. Reload your media tabs and start playback. Check that the connection reads “Connected to Stream Deck”.

You control sharing

Sending is off by default. No analytics or developer-operated upload service. Disable sending and save to stop forwarding and image requests. Page scripts can still observe media APIs; restrict site access or remove the extension to stop them.
