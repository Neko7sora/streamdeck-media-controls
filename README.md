# Stream Deck Media Controls v0.4.7

表示言語は日本語・英語に対応しています。プラグインの設定画面とキー／ダイヤルの案内は Stream Deck の表示言語、Chrome 拡張の設定・接続表示は Chrome の表示言語に従います。日本語以外の言語では英語を使用します。言語を変更した場合は Stream Deck を再起動し、拡張機能と設定画面を開き直してください。曲名・アーティスト名などの取得情報は翻訳せず、そのまま表示します。

Japanese and English interfaces are supported. Plugin settings and key / dial labels follow the Stream Deck language; extension settings and connection messages follow the Chrome UI language. ## 取得・表示・操作

アプリやサイトが公開した情報だけを扱います。欠損メタデータは内部で `null`、未知の数値は `null`、UI では `Unavailable` / `--:--` として扱います。ページタイトルを曲名として代用しません。API が返す空文字やゼロ値はネイティブ JSON にそのまま残る場合があります。

| 情報・機能 | Windows | Chrome | Stream Deck での利用 |
|---|---|---|---|
| アートワーク | GSMTC Thumbnail | Media Session artwork、サイズ・MIME 候補 | 通常キー / + に縦横比を維持して表示。Chrome 画像失敗時は Windows 画像、それもない場合は既定アイコン |
| アプリ / サイトアイコン | AUMID の登録ロゴ / Shell アイコン。実行ファイル名が一致する Audio Session があれば、その実行ファイルも参照 | ページの icon / apple-touch-icon / apple-touch-icon-precomposed と同じオリジンの /favicon.ico | Now Playing の右上 / + の状態表示の横に表示。favicon を優先し、欠損・取得失敗・デコード失敗時は Windows のアプリアイコン |
| 曲名・アーティスト | GSMTC | Media Session | 通常キー / +。欠損をページ名から推測しない |
| アルバム | GSMTC | Media Session | 設定画面の取得情報 |
| サブタイトル・アルバムアーティスト・ジャンル・トラック番号/総数・メディア種別 | 公開時のみ | 共通 API からは取得しない | 設定画面の取得情報 / native JSON |
| 再生状態 | GSMTC enum と表示用状態 | Media Session / アクセス可能な HTMLMediaElement | キーの状態記号 / + の状態文字 |
| 位置・長さ・シーク可能範囲 | GSMTC Timeline | HTMLMediaElement、観測後の setPositionState | + に位置・長さ・進捗を表示。再生中は取得時刻・速度から位置を補間。対応時は回転 / バーのタップでシーク |
| 再生速度 | GSMTC | HTMLMediaElement / 観測した setPositionState | 取得情報。速度変更 UI は未実装 |
| シャッフル・リピート | GSMTC | HTMLMediaElement の loop のみ（同義とは扱わない） | 取得情報。変更 UI は未実装 |
| 利用可能な操作 | GSMTC Controls | アクセスできる HTMLMediaElement の操作だけ | 未対応操作を拒否してアラート。ブラウザの次/前は直接操作しない |
| 再生 / 一時停止・停止・次/前 | 指定した GSMTC オブジェクトへ Try*Async | 再生/一時停止・停止・シークのみ、対象ドキュメントの HTML 要素へ | 基本操作 / Now Playing。従来のグローバルキーも設定で選択可 |
| 複数セッション・アプリ情報 | WinRT オブジェクト単位の一時 ID、AUMID | 接続元 + タブ + frame + document ID、ページ URL / タイトル | 各アクションの設定で選択。+ の長押しで順に切替 |
| マスター音量・ミュート | Core Audio、既定のマルチメディア出力 | ブラウザ要素の volume / muted は別の情報 | Volume Dial / + に Windows の選択対象の音量。回転で2%/tick、Volume Dial 押下/タップでミュート |
| アプリ別音量・ミュート | 同じ出力デバイスの Audio Session、PID / 実行ファイル名 | GSMTC やタブとは自動対応付けしない | 独立した音量対象リストで明示選択して変更 |
| buffered / seekable、ended、readyState、PiP、loop | 対応する共通 GSMTC 情報なし | アクセス可能な HTMLMediaElement | 設定画面の取得情報。専用の操作 UI は未実装 |
| 取得元・観測時刻 | observed_at、Timeline 更新時刻 | 受信時刻、補完時刻 | 取得情報。補完したフィールドの取得元も記録 |

## Windows x64 ビルド

Windows 10 1809+ / Windows 11、Stream Deck 7.1+、Node.js 24、Rust MSVC toolchain と Visual Studio C++ Build Tools / Windows SDK が必要です。CLI はプロジェクト依存に含まれます。

**Developer PowerShell for Visual Studio（x64）** でリポジトリを開きます。`cargo` / `node` / `npm` が PATH にあることを確認してください。

```powershell
npm ci
npm run check
npm run test:native
npm run test:smoke
npm run validate
npm run pack
```

`check` は JS 構文、TypeScript の SDK 型、JS テスト、Rust release ビルド、パッケージ資産と同梱画像ランタイムを検証します。`test:native` は Rust テスト（ローカル実行ファイルの Shell アイコン読み取りを含む）、`test:smoke` は実際の Windows API 読み取り・存在しない対象の操作拒否・終了確認です。再生や音量は変更しません。

Cargo.lock / package-lock.json を固定してビルドします。`link.exe not found` は C++ ツール未導入か開発用シェルの環境設定不備を確認してください。GSMTC が `0x80070005` を返す制限付きシェルでは、通常の対話 Windows ユーザー環境で実行してください。スキーマ取得エラーがある場合、CLI の「成功」表示だけを正式な検証成功と扱わないでください。

生成した `.streamDeckPlugin` をダブルクリックして導入できます。開発中は次も使用できます。

```powershell
npm run link
npm run restart
```

プラグインの `.sdPlugin/node_modules` は sharp のネイティブ画像処理ランタイムです。`bin` / `native` と一緒に配布してください。ビルドはその生成済み node_modules を毎回作り直します。依存のライセンスファイルも同梱します。

## 設定と操作

各アクションには、その操作で使う対象の設定を表示します。Now Playing 通常キーは表示・再生対象、音量操作は音量対象を選びます。Now Playing + は表示・再生対象と音量対象を別々に選べます。

設定画面の先頭に、編集中のキー／ダイヤルのアクション名を表示します。操作対象・ダイヤル操作を優先し、表示項目と文字送りは「表示のカスタマイズ」にまとめています。折りたたんだ状態でも表示中の項目数を確認でき、「すべて表示に戻す」でそのアクションに対応する表示項目だけを一括復元できます。操作対象や文字送りの設定は保持します。「詳細な操作設定」で従来のグローバルメディアキー、「Chrome 連携の設定」で拡張との連携登録を開けます。Chrome 未接続時は状態表示のリンクから連携設定へ移動できます。保存済みのグローバル操作を使っている場合は詳細設定を最初から開きます。選択対象の切断警告は一覧の受信後に、その操作で使用する対象だけに表示します。ダイヤルの案内は現在のモード・移動秒数・進捗バーの表示設定に従います。

Chrome 拡張の設定画面はライト／ダーク表示と狭い画面幅に対応し、「接続を再確認」で状態を再取得できます。初回設定の手順は接続成功時に折りたたみ、手動で開閉した状態はその画面を開いている間保持します。送信設定を変更すると「未保存の変更があります」と表示し、変更がある場合だけ「保存」を押せます。保存に失敗した場合は編集内容を保持して再試行できます。

Play / Pause・Previous Track・Next Track・Stop は、操作アイコンの下に対象アプリ／サイト名と曲名を表示します。取得できる場合はアプリ／サイトアイコンも添えます。自動選択でも、最後に表示したセッションへ操作を送ります。Toggle Mute・Volume Up・Volume Down は「PC全体」または対象アプリ名と音量・ミュート状態を表示し、Volume Dial でも同じ対象名を使います。長い名前はキー上でスクロールします。グローバル再生キーは「OS自動」、対象がない場合は「対象なし」や「切断済み」と表示します。基本操作の設定画面では、その操作で使う対象選択だけを表示します。

基本7キーと Volume Dial にも「表示する項目」があります。再生操作キーは操作アイコン・操作対象名・曲名・アプリ／サイトアイコン、音量／ミュートキーは操作アイコン・操作対象名・音量（%）・ミュート状態を個別に切り替えられます。Volume Dial は対象の種類・操作対象名・音量（%）・ミュート状態／操作ヒント・音量バーを切り替えられます。設定はキー／ダイヤルごとに保存され、初期設定と既存設定はすべて表示です。非表示の文字はスクロールせず、表示設定を変えても操作対象と操作内容は変わりません。

Now Playing / Now Playing + の「表示する項目」で、曲名・タイトル、アーティスト、アートワーク、アプリ／サイトアイコン、再生状態を個別に表示・非表示にできます。+ では再生位置（経過時間）、総時間、進捗バー、ダイヤル情報（移動秒数／音量）もそれぞれ切り替えられます。設定はキー／ダイヤルごとに保存し、すぐに反映します。初期設定と既存設定はすべて表示です。非表示の文字はスクロールせず、通常キーではその文字用の暗い背景も取り除きます。進捗バーを非表示にした場合は画面下部のタップも再生／一時停止になります。回転は選択したモード（シーク／音量）のまま利用でき、長押しでのセッション切替も維持します。

- 設定画面の先頭に Chrome の接続状態を常時表示します。「接続済み」は実際の通信確認、「メディアを受信中」は有効な Chrome セッションの受信を表します。再生ページがなくても接続を確認できます。「Chrome 連携を登録」の完了だけでは接続済みになりません。通常の状態・操作通信を接続確認にも使い、通信がない場合は約5秒ごとの受信ストリーム通知で確認します。旧ホストでは5秒ごとの接続確認を使います。Stream Deck 側では15秒間通信がないと未接続になります。設定画面がプラグインから6秒間応答を受け取れない場合も、接続済み表示を解除します。
- 設定画面は保存済みの対象を初期表示に反映し、候補一覧より先に届いた選択や切断済みの対象も保持します。項目を変更すると、その項目だけを更新します。遅れて届いた一覧応答で直近の設定変更を戻しません。一覧は変更通知で更新し、3秒間応答がない場合は軽い生存確認だけを送ります。項目が変わらない通知では選択欄を作り直さず、ドロップダウンやキーボードでの選択操作を維持します。
- 設定画面を開いたままプラグインを再起動しても、次の通信確認で一覧の購読を再登録し、候補と変更通知を復旧します。復旧待ちに変更した設定や、切断済みの選択対象は保持します。
- 設定画面の接続待ち・切断中は設定項目を無効にし、保存できない変更を防ぎます。切断時は設定画面を開き直してください。
- 自動表示は再生中のセッションを優先し、同じ再生状態の候補が複数あっても現在の対象を維持します。定期受信・再生位置の更新・Windows 現在セッションの変動だけでは切り替えません。初回や対象の切断時は、再生中の候補（なければ全候補）から Windows 現在セッション、更新時刻の順で選びます。現在の対象が一時停止・停止して別の対象が再生中なら切り替えます。表示・操作したい対象を固定する場合は明示選択できます。
- Chrome 補完には「Chrome の Windows セッション」「空でない同じ曲名・アーティスト」「アルバムが競合しない」「一致候補が1個」の条件が必要です。タイトルだけの一致では補完しません。
- 選択対象が消えた場合やヘルパー再起動後には、別セッションへ自動で切り替えません。設定画面で再選択してください。GSMTC の ID はヘルパー存続期間内だけ有効です。
- Chrome は拡張機能のローカル設定に接続元 ID を保存し、タブ ID が重なる別の Chrome 実行環境の表示・操作・差分更新を区別します。worker や Native Messaging ホストが再起動しても、接続元 ID は維持します。この方式への初回更新時はプラグインと拡張機能を更新し、明示選択していた Chrome 対象を一度選び直してください。旧拡張も従来形式で接続できますが、接続元の分離には新しい拡張が必要です。
- Now Playing はアートワーク・曲名・アーティスト・状態を表示し、押すと表示用に最後に送信したセッションへ再生/一時停止を要求します。
- アプリ / サイトアイコンはアートワークと別に表示します。favicon の取得には Chrome 拡張の更新・再読み込みと、再生ページの再読み込みが必要です。PNG / JPEG / WebP / ICO の favicon を32pxの PNG に変換して扱い、SVG は対象外です。Windows セッションへの favicon の補完は、曲名・アーティスト・アルバムの既存の一致条件を満たす一意の Chrome セッションから行います。TVerなどで両者のアーティスト・アルバムが空の場合は、同じタイトル、またはメディアを持つ最上位フレームのページタイトルと Windows タイトルが一致し、両側の候補が一意ならアイコンだけを補完します。曲情報・アートワーク・操作対象の照合条件は従来どおりです。Chrome セッションを直接選んだ場合の Windows アイコンも同じアイコン照合条件で取得します。どちらのアイコンも取得できない場合、アイコン欄は空になります。未登録の Win32 アプリでは実行ファイルを解決できず、アイコンが取得できないことがあります。
- 各キー／ダイヤルの設定にある「文字送りを有効にする」で、長い文字のスクロールをON/OFFにできます。初期設定と既存設定はONです。OFFでは先頭を固定表示し、表示範囲を超える部分は切り取ります。設定はキー／ダイヤルごとに保存され、すぐに反映します。ONに戻すと先頭から文字送りを再開します。
- Now Playing / Now Playing + の長い曲名・アーティスト名は、文字送りがONの場合、それぞれ独立して自動スクロールします。全文を一度画像化し、最大10fps・毎秒30px（通常キーは2倍解像度で描画）の速さで表示範囲を動かします。文字を1文字ずつ切り替えません。先頭と末尾で1.5秒止まり、末尾まで表示してから先頭へ戻ります。短い文字列は動かしません。再生位置の更新や一時停止ではスクロールをリセットせず、曲やセッションが変わると先頭から表示します。
- Now Playing + の曲名は上段の全幅を使い、アーティスト名はアートワークの横に表示します。通常キーはアートワークに状態・曲名・アーティスト名を合成し、文字の下に暗い背景を敷きます。文字は画像内に描画するため、Stream Deck のタイトル文字サイズには依存しません。全文は取得元から取得できた範囲（各500文字まで）です。描画済みの文字とアートワークを再利用し、ダイヤル画面には変わった項目だけを送信します。非表示時にはアニメーション対象から外れます。
- ページやプロファイルを切り替えて非表示になったキー・ダイヤルには、処理中だった画像を後から送信しません。同じアクションが再表示された場合も、前回の描画が操作対象やスクロールを復活させないようにします。
- 文字は Windows の Meiryo UI のフォントファイルを明示して描画します。未導入の場合は Yu Gothic UI、Segoe UI の順に利用します。フォントファイルは同梱しません。曲名は標準の太さで表示し、文字列や絵文字の有無による画像全体の縮小を行いません。
- Now Playing + はアートワーク・曲名・アーティスト・状態・位置/長さ・進捗を表示します。右回転＝早送り、左回転＝巻き戻しで、初期値は5秒/目盛りです。設定から1 / 5 / 10 / 30 / 60秒を選べます。保存済みの設定に1〜60秒の別の値がある場合も、その秒数を設定画面に表示して保持します。押下＝再生/一時停止、画面下部35pxの時刻・進捗領域をタップ＝対応時だけシーク、長押し＝セッション切替です。バーのタップは表示中の開始時刻・長さから移動先を求め、実際にシークできる範囲へ補正します。長さが未取得の場合はタップでシークしません。表示用に最後に送信したセッションだけを操作します。
- Now Playing + の「ダイヤル回転」を「音量」にすると従来どおり選択した Windows 音量を操作・表示します。シークモードでは右下に移動幅（例：±5s）を表示します。Volume Dial は引き続き音量専用です。
- 連続回転は移動量を積み上げ、操作が返るまでの回転をまとめて順に送信します。進捗バーのタップも同じ順序で処理し、送信待ちの回転やタップを最後に指定した位置で置き換えます。タップ直後の回転は、その指定位置から加減します。曲変更や非表示後に同じダイヤルを使う場合も、処理中のシークが完了してから次を送信し、古い待機操作は破棄します。Chrome のシーク可能範囲に隙間があっても小さな回転を積み上げ、次の範囲へ進めます。一時停止中の同じ位置の定期受信では積み上げを消さず、同じ位置への重複シークも抑えます。範囲の端で回しすぎても逆回転ですぐ戻せます。回転に必要な位置やシーク範囲が取得できない場合はアラートを表示します。
- Volume Dial は回転＝音量、押下またはタップ＝ミュートです。専用レイアウトの上段に「システム音量」／「アプリ別音量」、中央に「PC全体」または対象アプリ名を大きく表示します。音量・ミュート状態とバーは下段に表示し、長い対象名は全文をスクロールします。既存のダイヤルにも専用レイアウトを適用します。
- 基本7操作と Volume Dial で「従来のグローバルメディアキー」を有効にすると SendInput を使用します。このモードでは OS が操作対象を決めます。Now Playing にはこの設定を適用しません。
- 対象指定モードの基本操作は同じ対象設定にしてください。個々のキーとダイヤルはそれぞれ独立した設定を持ちます。
- Windows ヘルパーへの操作には5秒の期限を付けます。情報取得などで実行待ちのまま期限を過ぎた操作は破棄し、タイムアウト表示の後から再生や音量を変更しないようにします。既に Windows API に渡した操作を取り消すものではありません。

## Chrome 拡張（任意・オプトイン）

1. プラグインを起動します。Native Messaging ホストからの中継を受けるため、`127.0.0.1:39761` にだけ待ち受けます。
2. `chrome://extensions` の開発者モードで `chrome-extension` を「パッケージ化されていない拡張機能」として読み込みます。
3. Stream Deck アプリで Media Controls のアクションを選択し、設定画面で確認した拡張機能 ID を入力して「Chrome 連携を登録」をクリックします。入力した拡張機能 ID のみを許可し、現在のユーザーの HKCU に Native Messaging ホストを登録します。起動時や定期的な登録は行わず、ボタンを押したときだけ実行します。未導入の場合は Chrome で拡張を読み込んでから再度クリックしてください。Stream Deck に同梱された Node.js 24 を使い、ホストを LOCALAPPDATA にコピーします。管理者権限や別途 Node.js のインストールは不要です。拡張のオプションで送信を有効にしてください。トークンの貼り付けは不要です。

   手動で登録・修復したい場合は、リポジトリで次を実行できます（Node.js 24 が必要）。chrome://extensions で、このリポジトリから読み込んだ拡張機能の ID を確認してください。名前だけでは識別できないため、自動検出は行いません。

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts/register-chrome-native-host.ps1 -ExtensionId <確認した拡張機能ID>
   ```

   `-ExtensionId` は必須で、1つの ID だけを登録します。`-NodePath C:\path\to\node.exe` も指定できます。`-DetectOnly` は指定した ID の形式確認と表示だけを行い、インストール元の検証は行いません。Chrome のプロファイルから登録対象を選ぶことはありません。
4. 既に開いていたメディアページを再読み込みして、再生を開始します。Stream Deck の設定に Chrome の各フレームが現れるか確認してください。
5. 拡張更新後は Chrome で拡張を再読み込みしてください。ホスト更新や拡張 ID の変更後は「Chrome 連携を登録」を再度クリックします。ホストの更新を既存の接続にも反映する場合は拡張を再読み込みしてください。送信の有効化は自動では変更しません。

Chrome の拡張ボタンにも、緑の `ON`（Stream Deck に接続済み）、オレンジの `!`（未接続）、グレーの `OFF`（送信無効）を表示します。ツールバーに固定すると常時確認できます。ボタンをクリックすると接続状態と送信設定が開きます。未接続時には復旧手順を表示します。接続確認は既存の通信とメタデータや画像を含まない通知を使い、送信無効時は行いません。

Chrome の設定画面は、接続確認の応答が6秒間ない場合に「接続を確認できません」と表示し、次の定期確認で復旧を試みます。状態通知の接続も定期確認で応答停止を検出すると作り直し、編集中の送信設定を保持したまま復旧します。送信設定の保存後は改めて確認し、保存前・切断前の古い応答や期限切れの応答で接続表示を戻しません。

アートワークや favicon はバックグラウンドで取得し、画像の応答を待たずに曲情報と操作要求を中継します。新しい通信方式では取得完了時に画像参照の差分を通知し、旧ホストでは次のページ情報更新で反映します。同じURLの取得は共有し、SHA-256で同じ内容を識別して一度だけローカル転送します。受信キャッシュの失効・再起動時には必要な画像を再送します。同じ画像を再取得している間はキャッシュを表示し、曲や画像候補が変わった場合は前のアートワークを引き継ぎません。HTTPエラー・非対応形式・容量超過などで画像を採用できない場合は、残りのダウンロードを中断してから次の候補へ進みます。タブを閉じた場合や送信設定を変更した場合は、処理中の画像取得も取り消します。

この接続表示を追加する更新では Native Messaging ホストも変更しています。プラグインを再起動した後に「Chrome 連携を登録」をもう一度押し、Chrome 拡張を再読み込みしてください。

通信経路は「Chrome 拡張 → Native Messaging（標準入出力）→ Node.js ホスト → 認証付き localhost HTTP → Stream Deck プラグイン」です。拡張は localhost に直接接続せず、秘密トークンも保持しません。ホストは Chrome の allowed_origins に登録した拡張だけが起動できます。ローカルユーザーが直接ホストを実行することを防ぐ仕組みではありません。

旧版で登録済みの場合も、更新後に正しい ID で再登録し、Chrome を完全に終了して起動し直してください。既存の許可リストは再登録で置き換わり、Chrome の終了で起動済みのホスト接続も終了します。

登録解除は `Remove-Item -LiteralPath 'HKCU:\Software\Google\Chrome\NativeMessagingHosts\dev.n7s.media_controls'` で行います。登録ボタンの処理中は、完了を待ってから解除してください。

拡張のオプションは保存済み設定の読み込みが完了してから編集できます。読み込みに失敗した場合は既存設定の上書きを防ぐため編集・保存を無効にし、再読み込みを案内します。保存中も入力と重複保存を止め、保存が失敗した場合は入力内容を残して再試行できます。

Web サイト全般の Media Session と CDN 画像を扱うため HTTP / HTTPS の広いホストアクセスを宣言しています。`tabs`、Cookie、履歴、webRequest、scripting、音声キャプチャの権限は使いません。Chrome のサイトアクセス設定で対象サイトを絞れます。無効時にはメタデータや画像を送信・取得しません。既存の表示は最長約15秒で失効します。

無効化前に要求した応答が遅れて戻っても、その応答の操作は実行しません。同じ設定で再度有効にした場合も、古い応答を破棄し、新しい更新から操作を再開します。既にページへ送信した操作の結果通知は継続します。

Chrome の操作は、曲名に加えてページ内の再生要素・メディアソース・曲情報の変化を識別して照合します。同じ曲名や曲名なしの動画へ切り替わった場合も、切り替え前の操作を新しい対象へ送らず拒否します。メディアソースの URL 自体はこの照合用に送信しません。この変更を反映するには、プラグインの更新後に Chrome 拡張と再生ページの両方を再読み込みしてください。古いページスクリプトから届く情報は表示できますが、対象を確認できない操作は拒否します。

ページから拡張への更新は250ms間隔に抑えつつ、その間に届いた最新の状態を保持して次の送信へ反映します。一時停止やシークの最後の更新を破棄せず、定期スナップショットを待たずに引き渡します。

トークンはホストがファイルから読み取り、拡張やページへ渡しません。Chrome storage.local のアクセスも TRUSTED_CONTEXTS に制限します。Windows のフォルダー/既存トークンには現在のユーザーと SYSTEM の DACL を設定します（ローカル管理者に対する秘匿機能ではありません）。読み込み・ACL 設定に失敗した場合、ブリッジを起動しません。不正な既存トークンをリセットする場合は、プラグイン停止後にファイルを削除して再起動してください。トークンを共有・コミットしないでください。

ページ URL の userinfo・クエリ・フラグメントは送信前に除去します。画像取得は公開 HTTPS URL の上位3候補まで、credentials omit / redirect error / no-referrer、350,000 byte 上限・タイムアウト付きです。既知のプライベート IP・非標準ポート等を拒否します。URL・宣言された画像形式が対象外の候補や重複 URL は順位付けの前に除外します。favicon は最大3回の取得のうち1回を同じオリジンの /favicon.ico に確保し、多数のリンクや取得失敗があってもフォールバックを試せるようにします。認証 Cookie、保存認証情報、音声/映像ストリーム、DRM データは取得しません。画像 CDN が認証を要求する場合は取得失敗として扱います。

## 更新・復旧・制限

GSMTC は常駐ヘルパーでセッション/現在対象・メタデータ・再生・タイムラインの変更通知を購読し、約1秒のポーリングで補います。プラグインはヘルパーの `--delta` 形式を使い、変更部分と未転送の画像だけを受信します。変更がない間は5秒ごとの短い生存通知だけを受け取ります。単独実行と `--watch` の従来JSON形式も維持します。Core Audio は約1秒ポーリングで変更を通知します。Core Audio のネイティブ callback、全出力デバイスの列挙、音量の絶対値入力 UI は未実装です。

Chrome はページイベントと約1秒間隔のローカル観測を使います。新方式では状態変更・位置のずれを即時通知し、通常再生中は5秒ごとに再同期します。メディアのないページでは初回と状態変化時だけ送信します。操作指示は認証付きHTTP受信ストリームとNative Messagingから即時配信し、状態更新を待ちません。旧ホストでは従来の1秒間隔で操作を受信します。MV3 worker は再起動ごとに設定を読み直します。処理はフレームごとに直列化し、同時に8フレームまで処理します。空きができると待機中のフレームを順に再開し、処理済みフレームの待機状態を解放します。document ID を使って移動前のページへの誤操作を避け、タブ終了時には待機処理と後続の操作を打ち切ります。worker 停止・ホスト切断時は次のメッセージで再接続します。バックグラウンドタブのタイマー制限では15秒の TTL を超えて表示が消える場合があります。操作の結果が不明な場合、再生トグルを自動再送しません。

Now Playing + は250msごとに表示内容を見直します。Windows は GSMTC の Position / LastUpdatedTime、Chrome は HTML 要素の currentTime または観測した setPositionState を基準とし、再生中だけ経過時間と再生速度で補間します。一時停止・停止や Chrome のバッファ待ち / シーク中は補間しません。新しいサンプルで位置を補正し、公開された末尾を超えて進めません。長さや位置が未公開の場合は `--:--` のままです。setPositionState だけのページでは再生状態の切り替わりを次の観測時に反映するため、最大約1秒のずれが生じ得ます。

ネイティブ応答停止は約12秒でプロセスを終了し、状態消去後に再起動します。ネイティブ応答は1行64 MBまでとし、超過したデータは解析・表示せず、ヘルパーを再起動します。入出力パイプの切断も検出し、保留中の操作を失敗として返してから復旧します。古いヘルパーの終了通知や応答で、新しいヘルパーの操作を取り消しません。タイムアウトした対象指定操作をグローバルキーへ置き換えません。UI は同じ内容の再送を抑止します。

Windows 画像は1 MiB、デコードは PNG/JPEG/WebP・約16.8メガピクセルまでです。アニメーション・SVG・破損画像は表示しません。Windows スナップショットの画像予算、キャッシュ件数/容量、Chrome タブ状態、同時処理数、HTTP 本文に上限があります。失敗画像のキャッシュは再試行期限付きです。GSMTC の全プロパティは完全な OS トランザクションとして読み取れないため、厳密な同時刻性は保証しません。

Media Session にはサイトの action handler を外部から呼び出す標準 API がありません。Chrome 直接操作は一意に選べる HTMLMediaElement に限り、次/前、Web Audio のみの再生制御、閉じた Shadow DOM、アクセス不能なフレーム、非対応画像は unavailable です。`setPositionState` はページへの挿入後に成功した呼び出しだけを観測し、未観測の位置を推測しません。複数の HTML メディア要素が同時再生して一意に選べない場合は要素情報・操作を付けません。

## 実機の受け入れ確認

Chrome の複数タブと Windows の2種類以上のメディアアプリで、次を確認してください。

1. 拡張なしで GSMTC の曲名・画像・位置・操作可否が取得できる。
2. 拡張ありで一致する曲だけを補完し、違う曲や曖昧な候補は混合しない。
3. 曲送り・アート更新・欠損画像・縦長画像・ライブ配信・停止・再生速度変更が表示に反映する。
4. 再生対象と音量対象を別々に選び、意図した対象だけを操作する。未対応操作はアラートになる。
5. + の押下・回転・バーのタップ・長押しと、無効なシーク範囲を確認する。
6. タブ移動/終了、worker 停止、プラグイン再起動、ホスト未登録・切断、音声デバイス切替から復旧する。
