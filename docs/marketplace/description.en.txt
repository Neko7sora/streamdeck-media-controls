Control Windows media playback and volume from Stream Deck. See available album artwork, track titles and artists on your keys, and use Stream Deck + dials for volume or seeking. Choose playback and audio targets separately for supported Windows apps.

Includes play/pause, previous track, next track, stop, mute, volume keys, Volume Dial and Now Playing actions. Customize visible information and text scrolling per action. English and Japanese interfaces are included.

Requires Windows 10 version 1809 or later (x64), or Windows 11 (x64), and Stream Deck 7.1 or later. Dial actions require Stream Deck +. macOS is not supported. Information and controls depend on what each app exposes through Windows media APIs.

Optional Chrome integration requires Chrome 111 or later, manually loading the supplied companion extension, registering the local bridge and enabling sending in its settings. Browser playback control requires an accessible HTML media element; direct previous/next track control is unavailable. No account is required; media information is processed locally. Artwork requests may contact the source website or image host.

AI assistance was used in plugin development, review, listing text and supporting media code. Supporting images use plugin assets and code-rendered previews with fictional sample media.
