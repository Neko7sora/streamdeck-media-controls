Media Controls 1.0.1 (STABLE)

Patch release.

Fixed a missed seek step when turning a Stream Deck + dial repeatedly.

Chrome integration now authenticates the local bridge over HTTPS using a per-user certificate. After updating, register the local bridge again by following the setup guide.

Improved development checks, packaging workflows and guidance for incomplete release reviews.

Chrome integration is optional and requires installing the companion extension from the Chrome Web Store, local bridge registration and enabling sending. Available media information and controls depend on the selected app or browser page. Direct browser previous/next track control is unavailable.
