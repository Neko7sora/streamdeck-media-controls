Media Controls 1.0.0 (STABLE)

Initial release.

Control Windows media playback and master or per-app volume from Stream Deck. Display artwork and track information on keys, and use Stream Deck + dials for volume or seeking. Includes English and Japanese interfaces, smooth text scrolling and per-action display customization.

Optional Chrome integration provides browser media information, supported playback controls and connection status in the plugin settings and companion extension. Playback commands use a separate channel from state updates, with incremental updates, image caching and settings change notifications.

Chrome integration is optional and requires manual installation of the companion extension, local bridge registration and enabling sending. Available media information and controls depend on the selected app or browser page. Direct browser previous/next track control is unavailable.
