# Media Controls Q&A

Media Controls を使う方に向けた、導入・操作・トラブル対応のよくある質問です。リポジトリの現行仕様を基にしています。詳しい仕様は [README](../README.md)、版ごとの変更は [リリース履歴](version-history.md) を参照してください。

## 導入と対応環境

### Q1. 何ができますか？

Windows のメディアの再生／一時停止・停止・前へ／次への移動、PC全体またはアプリ別の音量・ミュートを Stream Deck から操作できます。Now Playing ではタイトル・アーティスト・アートワーク・再生状態を表示します。取得できる情報や利用できる操作は、対象のアプリやサイトによって異なります。

### Q2. どの環境で使えますか？

対応環境は Windows 11 以降（x64）、Stream Deck 7.1 以降です。ダイヤル操作には Stream Deck + が必要です。macOS は非対応です。任意の Chrome 連携には Chrome 111 以降が必要です。

### Q3. どうやって使い始めますか？

1. README の [インストール案内](../README.md#インストール--installation) からプラグインを導入します。
2. Stream Deck アプリで Media Controls のアクションをキーまたはダイヤルに追加します。
3. メディアアプリで再生を開始します。
4. アクションの設定で再生対象を選ぶか、自動選択を使います。音量アクションでは音量対象を選びます。

Now Playing に対象のメディア情報が表示され、対応する再生操作ができることを確認してください。詳しい導入手順は [セットアップガイド（英語）](marketplace/setup.md) にあります。

### Q4. Chrome 拡張や Node.js のインストールは必須ですか？

Chrome 拡張は任意です。拡張がなくても、Windows が公開するメディア情報と操作を利用できます。

ストアから導入したプラグインの利用や、設定画面の「Chrome 連携を登録」には、別途 Node.js をインストールする必要はありません。Stream Deck 同梱の実行環境を使います。ソースからのビルドやスクリプトによる手動登録には Node.js 24 以降などの開発環境が必要です。

## 対象の選択とキー操作

### Q5. 再生対象と音量対象は何が違いますか？

再生対象は、メディア情報の表示や再生／一時停止などを行うメディアセッションです。音量対象は、Windows の「PC全体」またはアプリのオーディオセッションです。両者は自動で対応付けません。

たとえば Chrome の動画を再生対象にしても、音量対象が「PC全体」なら PC全体の音量が変わります。Chrome のタブ単位の音量調整には対応していません。設定はキー／ダイヤルごとに独立しているため、複数の操作を同じ対象にそろえたい場合は、それぞれ設定してください。

### Q6. 自動選択はどの再生対象を選びますか？

再生中の対象を優先します。同じ再生状態の候補が複数ある場合は、現在の対象を維持します。現在の対象が一時停止・停止し、別の対象が再生中なら切り替えます。初回や対象の切断時は、再生中の候補（なければ全候補）から Windows の現在セッション、更新時刻の順で選びます。

対象を固定したい場合は、アクションの設定で明示的に選択してください。再生操作は、最後に表示した対象へ送ります。

### Q7. 「切断済み」と表示され、操作できません。

選択したアプリの終了やタブの移動・終了、Windows ヘルパーの再起動で、保存済みの対象が使えなくなる場合があります。明示選択した対象が消えても、別の対象には自動で切り替えません。

アプリやページを開いて再生し、アクションの設定で対象を再選択してください。対象名とメディア情報が表示されることを確認します。設定画面が切断中で編集できない場合は、Stream Deck の起動を確認し、設定画面を開き直してください。

### Q8. 「従来のグローバルメディアキー」は何ですか？

基本の再生・音量キーと Volume Dial で、Windows が操作対象を決める従来のキー送信を使う設定です。再生キーの対象表示は「OS自動」になります。特定の対象を操作したい場合は、この設定を無効にして対象を選んでください。Now Playing にはこの設定を適用しません。

## Stream Deck + と表示の設定

### Q9. Now Playing + のダイヤルはどう操作しますか？

| 操作 | 動作 |
|---|---|
| 右回転／左回転 | 初期設定では早送り／巻き戻し。1目盛り5秒 |
| ダイヤル押下 | 再生／一時停止 |
| タッチ画面下部の時刻・進捗領域をタップ | 対応している場合、指定位置へ移動 |
| タッチストリップを長押し | 再生対象を順に切り替え |

設定で移動幅を 1・5・10・30・60秒から選べます。「ダイヤル回転」を「音量」にすると、回転で選択した Windows 音量対象を調整します。この場合も押下は再生／一時停止です。

### Q10. Volume Dial と Now Playing + の音量モードは同じですか？

どちらも選択した Windows 音量対象を回転で調整できます。Volume Dial は音量専用で、押下またはタップでミュートを切り替えます。Now Playing + は音量モードでも、押下で再生／一時停止を操作します。

### Q11. タイトルや画像を隠したり、文字送りを止めたりできますか？

各アクションの「表示のカスタマイズ」で変更できます。「表示する項目」からタイトル・アーティスト・アートワークなどを選び、「文字送りを有効にする」をオフにすると長い文字の先頭を固定表示します。表示しきれない部分は切り取られます。設定できる項目はアクションによって異なります。

設定はキー／ダイヤルごとに保存されます。「すべて表示に戻す」で、そのアクションの表示項目を復元できます。Now Playing + の進捗バーを非表示にすると、画面下部のタップも再生／一時停止になります。

### Q12. 日本語表示にできますか？

プラグインの設定や操作案内は Stream Deck の表示言語、Chrome 拡張は Chrome の表示言語に従います。日本語以外の言語では英語を使います。言語を変更したら Stream Deck を再起動し、拡張機能と設定画面を開き直してください。タイトルやアーティスト名など、取得した情報は翻訳しません。

## Chrome 連携

### Q13. Chrome 連携はどう設定しますか？

1. README の [Chrome 拡張の案内](../README.md#chrome-拡張任意オプトイン) から拡張を導入します。
2. 導入した拡張の提供元を確認し、拡張の設定の「はじめての設定」を開きます。ID・拡張機能名・バージョンは自動表示されるので、「ID をコピー」を押します。ストア版の ID は `iagfcpchjohmpnnlcgppdcadehinhdpa` です。
3. Stream Deck の Media Controls アクションで「Chrome 連携の設定」を開き、確認した ID を入力して「Chrome 連携を登録」を押します。
4. 拡張の設定で「ブラウザからの送信を有効化」をオンにし、「保存」を押します。送信は初期状態では無効です。
5. 既に開いていたメディアページを再読み込みし、再生を開始します。
6. 拡張に「Stream Deck に接続済み」、プラグイン設定に「メディアを受信中」と表示されることを確認し、再生対象を選びます。

登録には管理者権限やトークンの貼り付けは不要です。開発用の拡張は ID が異なる場合があるため、実際に導入した拡張の ID を使ってください。

### Q14. 登録したのに未接続です。何を確認すればよいですか？

登録の完了は、通信の成功を意味しません。次の順に確認してください。

1. Stream Deck とプラグインが起動していることを確認します。
2. 拡張で送信を有効にして保存し、「接続を再確認」を押します。
3. 登録した ID が、`chrome://extensions` に表示される拡張の ID と一致するか確認します。違う場合は正しい ID で再登録します。
4. 拡張機能とメディアページを再読み込みします。ID を変更した場合は Chrome を完全に終了して起動し直します。

拡張の「Stream Deck に接続済み」、またはプラグイン設定の「Chrome：接続済み」で通信を確認できます。接続だけなら、再生ページがなくても確認できます。「メディアを受信中」は、さらに有効な Chrome の再生対象を受信している状態です。

### Q15. 更新後に Chrome 連携が動かなくなりました。

以前の HTTP 方式から更新する場合は、次の手順でローカル連携を更新してください。

1. 拡張の送信を無効にして保存します。
2. プラグインを更新し、再起動します。
3. 導入済み拡張の ID を確認して「Chrome 連携を登録」を実行します。
4. Chrome を完全に終了して起動し直します。
5. 送信を再び有効にして保存し、メディアページを再読み込みします。

プラグインの更新だけでは、登録済み・実行中の中継ホストは更新されません。現在の方式は証明書で接続先を確認する HTTPS を使います。詳しくは [セットアップガイドの更新手順](marketplace/setup.md) を参照してください。

### Q16. Chrome の「次へ」「前へ」が操作できません。

Chrome セッションへの直接操作は、アクセス可能な HTML メディア要素の再生／一時停止・停止・シークに限られます。「前へ」「次へ」の直接操作には対応していません。Windows 側のセッションがその操作に対応している場合は、Windows の対象を選んで操作できます。

Web Audio のみを使うプレーヤー、閉じた Shadow DOM、アクセスできないフレームなども直接操作の対象外です。複数のメディア要素が同時再生し、操作先を一意に決められない場合も操作できません。

## 表示や操作のトラブル

### Q17. タイトル・画像・時間が表示されません。

まず対象を選び直し、「表示する項目」で必要な項目が有効か確認してください。そのうえで、次の点を確認します。

| 症状 | 確認すること |
|---|---|
| タイトルやアーティストがない | アプリやサイトが情報を公開しているか。タイトルがない場合は取得済みのページ名を表示し、それもなければ取得不可の表示になります |
| アートワークがない | 画像が公開されているか。Chrome 画像の取得に失敗すると Windows 画像、それもなければ既定アイコンを使います |
| サイトアイコンがない | 拡張の設定後にページを再読み込みしたか。SVG や認証が必要な画像など、取得・表示できない形式もあります |
| 時間が `--:--` になる | アプリやページから位置・長さを取得できているか。未公開の時間は推測して表示しません |

Windows と Chrome の情報は、タイトル・アーティストなどの条件が一致し、候補が一意の場合に補完します。拡張が接続済みでも、すべての情報が必ず表示されるわけではありません。

### Q18. ダイヤルでシークできず、アラートが出ます。

Now Playing + の「ダイヤル回転」がシークに設定されているか、正しい再生対象を選んでいるか確認してください。シークには、対象が操作に対応し、位置やシーク可能範囲を取得できている必要があります。進捗領域のタップには長さの情報も必要です。

ライブ配信などで位置や範囲を取得できない場合は、シークできません。別の対応メディアで確認し、そのメディアでは移動できる場合は、元のアプリやページが公開する情報・操作の制限が考えられます。

### Q19. バックグラウンドの Chrome タブが一覧から消えます。

Chrome のバックグラウンド制限などで、ページから15秒間更新を受け取れないと、その再生対象は失効する場合があります。拡張との接続が続いていても、古いメディア情報を表示し続けることはありません。

対象のタブを開き、必要に応じて再読み込みして再生してください。一覧に戻ったら、明示選択していた対象を再選択します。

## データと問い合わせ

### Q20. 再生情報は外部に送られますか？ 連携を止めるには？

メディア情報は PC 内で処理し、開発者が運営するアップロード先やアクセス解析はありません。Chrome 連携を有効にすると、メディア情報・画像・ページ名・認証情報やクエリなどを除いたページ URL・対象識別子などを、ローカルのプラグインへ渡します。音声・映像ストリームや DRM データは取得しません。

アートワークやサイトアイコンの取得時には、元のサイトや画像配信先へ HTTPS 通信を行います。その通信先には通常のリクエスト情報が伝わり、画像 URL にはサイトが付けたクエリが残る場合があります。

転送と新たな画像取得を止めるには、拡張の「ブラウザからの送信を有効化」をオフにして保存します。最後の表示は約15秒残る場合があります。ページ内でのメディア API の観測も止めたい場合は、拡張のサイトアクセスを制限するか拡張を削除し、既存タブを再読み込みするか Chrome を再起動してください。ローカル登録やファイルの削除手順は [データとプライバシー（英語）](marketplace/privacy.md) にあります。

### Q21. 解決しない場合はどこに問い合わせますか？

[GitHub Issues](https://github.com/Neko7sora/streamdeck-media-controls/issues) に、次の情報を添えて問い合わせてください。

- Windows、Stream Deck、プラグインのバージョン。Chrome 連携を使う場合は Chrome と拡張のバージョン。
- 使用したアクション、再生対象・音量対象、自動選択か明示選択か。
- 再現手順、期待した動作、実際の表示やアラート、接続状態。
- 対象アプリや、公開してよい範囲のサイト情報。

Issue は公開されます。ログにはローカルパスや識別子が含まれる場合があるため、共有前に内容を確認し、トークン・個人情報・非公開の再生情報を除いてください。
