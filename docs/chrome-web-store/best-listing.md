# Chrome ウェブストア掲載ページの準備

確認日: 2026-10-25（Asia/Tokyo）。対象は Chrome 公式の [優れたリスティング ページの作成](https://developer.chrome.com/docs/webstore/best-listing?hl=ja) と [画像の提供](https://developer.chrome.com/docs/webstore/images?hl=ja)。

原稿と素材はリポジトリに用意済み。ダッシュボードへの登録と掲載プレビューは未実施。公開までの全体の残作業は [対応記録](../chrome-web-store.md) を参照。

## 項目別の対応

| 項目 | 用意したもの・確認内容 | 提出時の確認 |
|---|---|---|
| 概要 | 日英の `summary` は manifest の説明と一致し、132文字以内。ブラウザの情報を同じ PC のプラグインへ送る用途と必要環境を明示 | 検索結果の表示でも用途が伝わるか確認 |
| 詳細説明 | 概要、短い機能リスト、必要環境、設定、データの扱い、制限の順。プレーンテキスト版を JSON から生成 | 実際のプラグイン配布・設定手順と照合し、全文を貼り付ける |
| ストアアイコン | 128×128 PNG、透明背景上の直径112pxの既存円形マーク。プロモーションにも同じマークと紺・シアンを使用 | 明暗の背景と小さい表示で識別できるか確認 |
| スクリーンショット | 日英各1枚、1280×800 PNG。初期状態の実設定画面を撮影。外枠・余白を後付けせず、成功状態を演出しない | 最新版との一致、縮小時の可読性を確認。設定画面内の背景は実UIの一部。実機動作の画像・動画は未用意 |
| 小型プロモーション | 440×280 PNG。既存の製品マークを中心に、ブラウザからキー表示への連携を文字なしの図で表現 | 画像全体と220×140への縮小で目視確認。実機写真・実画面のキャプチャではない |
| マーキー（任意） | 1400×560 PNG。同じ図と色で統一 | 700×280への縮小とダッシュボードでの表示を確認。採用や掲載順位を保証する素材ではない |
| その他のフィールド | プロジェクトの HTTPS ホームページと Issues を日英共通で指定 | ログインなしの閲覧・必要環境からの導入経路を確認。公開ポリシーURLは未設定。問い合わせ先は GitHub Issues に確定 |

スクリーンショットは各言語1枚で最低枚数を満たす。最大5枚は推奨であり、同じ画面で枚数だけを増やさない。追加する場合は実機で確認した主機能や設定手順を撮影し、説明だけの図を実際の画面として扱わない。現時点では Stream Deck 上の表示・操作を写真や動画で示せていないため、その訴求は今後の改善項目。

## 再生成と検査

```powershell
npm run chrome:listing:build
npm run chrome:store:check
```

`listing.*.json` が編集元。`description.*.txt` は直接編集しない。画像は [生成スクリプト](../../scripts/build-chrome-listing.mjs) が既存SVGを描画する。画像生成モデルは使用しない。[生成記録](../../assets/chrome-web-store/listing-assets.json) に編集元と出力の SHA-256 を保存し、検査で古い原稿・寸法違い・生成後の変更を検出する。アイコンや実画面を変更した場合の再生成手順は [全体の手順](../chrome-web-store.md#再生成と検査) を参照。

機械検査で判定するのは文字数・参照・寸法・整合性。説明の正確さ、画像の見やすさ、商標・権利、リンクの到達性は実物と掲載プレビューで確認する。

今回、プロモーション画像2種は原寸と半分のサイズで目視し、マーク・連携の図が識別でき、文字切れや透明な外周がないことを確認した。掲載素材のローカル検査と変更したスクリプトの構文検査は通過。既存のブラウザテストの再実行は、実行環境に Playwright 用 Chromium がなく起動できなかったため未確認。既存スクリーンショットのハッシュ検査は通過している。

2026-10-26 の追加監査・修正・公開条件は [総合監査](../guideline-audit.md) を参照。
