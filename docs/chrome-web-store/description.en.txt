See browser media details on Stream Deck with the Media Controls plugin on your Windows PC. This companion extension needs the plugin and local bridge setup to work.

Main features
- Add available track titles, artist details and artwork to Stream Deck.
- Play, pause, stop and seek accessible HTML audio and video elements.
- Check connection or disabled status with the toolbar badge.
- Choose when to send media information; sending is off by default.

Requires Windows 10 version 1809 or later (x64) or Windows 11 (x64), Stream Deck 7.1 or later, the Media Controls plugin, Chrome 111 or later and local bridge registration. Setup from the plugin uses Stream Deck's bundled runtime; a separate Node.js installation is only needed for the manual registration script. The extension cannot work on its own. Dial actions require Stream Deck +. macOS is not supported.

Setup: install the companion plugin, open Setup Chrome integration in its action settings, enter this extension's ID from chrome://extensions and register the local host. Enable sending in this extension and save, then reload your media tabs. The toolbar badge shows connection or disabled status.

Sending is off by default. When enabled, media information, page titles and page addresses without credentials, queries or fragments are passed to the plugin through a local native host. Page scripts may observe media APIs even when sending is disabled; use Chrome site access controls or uninstall to stop them.

Artwork and site icons are requested from public HTTPS image hosts, which receive your IP address and the requested image URL. There is no account, advertising, analytics or developer-operated media upload service.

Metadata and controls depend on each site. Direct next/previous track commands, Web Audio-only players, closed Shadow DOM and inaccessible frames are not supported. Browser-tab volume control is not provided; the plugin uses Windows audio targets.

Questions and support: https://github.com/Neko7sora/streamdeck-media-controls/issues. Issues are public; do not post personal information, tokens or unreviewed logs.
