# 翻訳の追加・変更

翻訳元はこのフォルダーの JSON ファイルです。設定画面、プラグインの表示文言、Chrome 拡張で同じカタログと翻訳処理を共有します。

JSON はビルド時に JavaScript へ埋め込まれます。実行時の JSON 読み込みや翻訳サーバーへの通信はありません。ブラウザー向けの生成ファイルは圧縮し、起動時に読み込みます。代替言語の解決と `{count}` などの変数の解析は言語選択時だけ行い、画面更新時はメモリー上の辞書を参照します。同じ言語の再指定では辞書を作り直しません。

1. `en.json` をコピーして `fr.json`、`de.json`、`pt-BR.json` などの言語コードで保存します。ファイル名は標準の BCP 47 表記にします。
2. キーを変えずに値を翻訳します。`{count}` や `{seconds}` は名前を変えずに残してください。文中の位置は変更できます。
3. `npm run locales:build` を実行します。JSON の追加は自動検出されるため、言語一覧やアプリのコードを編集する必要はありません。
4. `npm run check` で検証し、Stream Deck と Chrome で対象言語を選んで表示を確認します。翻訳元と生成ファイルを一緒にコミットしてください。

未翻訳のキーは省略できます。例えば `fr-CA` の項目がなければ `fr`、そこにもなければ `en` の文言を使用します。未対応言語は英語へ戻ります。日本語・英語のキーを追加する場合は、まず英語の基準カタログに追加してください。

従来から英語表示だった再生状態や短いダイヤル表示は、日本語カタログでも英語へのフォールバックを使い、既存の表示を維持しています。

文言は `t("キー", {count: 件数})`、HTML は `data-i18n="キー"` で参照します。キーは文言を修正しても変更しない識別子です。HTML 内のテキストは初回読み込み用の英語表示で、実行時はカタログを使用します。翻訳はプレーンテキストとして挿入され、HTML は実行されません。曲名などの外部メタデータは翻訳しません。

`src/locale-data.generated.ts`、`dev.local.media-controls.sdPlugin/ui/localization.js`、`chrome-extension/localization.js` は生成物です。直接編集せず、JSON を編集して再生成してください。通常のプラグインビルドでも再生成します。watch 実行中に翻訳を編集した場合は `npm run locales:build` を実行し、設定画面／拡張機能を再読み込みしてください。

`npm run locales:check` は生成物の更新漏れ、未知のキー、空の訳文、プレースホルダーの不一致を検出します。複数形の分岐は自動処理しません。必要な言語では件数に依存しない表現を使うか、複数形ルールを翻訳処理に追加してください。
